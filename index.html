Credential requirements

  • OpenAI API: server-side OPENAI_API_KEY and model configuration.
  • Scopus: Elsevier API key and eligible API entitlement / institutional access.
  • Web of Science: Clarivate API key and applicable subscription / API entitlement.
  • OpenAlex / Crossref: public metadata APIs; provide a polite email / contact identifier where supported.

API key possession does not automatically grant access to licensed bibliographic data. See official provider terms before enabling institutional use.
